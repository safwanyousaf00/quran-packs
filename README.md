# Quran packs — source data

Tafsir and translation files collected for Quran Verse Finder's downloadable
books, kept here as they were received, one zip per book. `manifest.json`
lists each file with its language, source, size and SHA-256.

The texts belong to their authors, translators and publishers. Each file is
credited to where it came from:

- **QuranEnc** (quranenc.com) — republished under its terms: no modification,
  credit and version shown, kept up to date.
- **QUL** (qul.tarteel.ai), **spa5k/tafsir_api**, **fawazahmed0/quran-api** —
  permission from the rights holders is being sought; these are held here for
  that purpose and are not yet offered in the app.

To have a file removed, open an issue.
